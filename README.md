Material de estudo com aulas introdutórias de JavaScript. O repositório reúne exemplos práticos para treinar sintaxe, interação com HTML, manipulação do DOM e exercícios básicos de lógica.

## Conteúdo

- Aulas separadas por pasta.
- Exemplos com `index.html` e `script.js`.
- Exercícios de revisão.
- Práticas com eventos, condições, repetições e manipulação de página.

## Tecnologias

- JavaScript
- HTML5
- CSS3
- Git e GitHub
