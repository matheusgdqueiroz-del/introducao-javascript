Material de estudo com aulas introdutorias de JavaScript. O repositorio reune exemplos praticos para treinar sintaxe, interacao com HTML, manipulacao do DOM e exercicios basicos de logica.

## Conteudo

- Aulas separadas por pasta.
- Exemplos com `index.html` e `script.js`.
- Exercicios de revisao.
- Praticas com eventos, condicoes, repeticoes e manipulacao de pagina.

## Tecnologias

- JavaScript
- HTML5
- CSS3
- Git e GitHub
